# Code of Conduct

## Our Pledge

We want Foodly to be a welcoming, respectful, and productive open-source project. Everyone participating in this repository is expected to help create an environment where people can contribute without harassment, discrimination, or personal attacks.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially when discussing bugs or review feedback.
- Focus criticism on ideas, code, and product decisions, not people.
- Welcome contributors with different levels of experience.
- Keep discussions relevant to the project and its users.

## Unacceptable Behavior

- Harassment, intimidation, insults, or personal attacks.
- Discriminatory language or behavior.
- Sexualized language or imagery.
- Publishing private information without consent.
- Repeated disruption of issues, pull requests, or project discussions.
- Any behavior that makes the project unsafe or hostile for contributors.

## Enforcement

Project maintainers may remove content, close discussions, block users, or take other appropriate action when this code of conduct is violated.

If you experience or observe unacceptable behavior, contact the repository maintainers through GitHub. Reports will be reviewed with care and handled as privately as possible.

## Scope

This code of conduct applies to all project spaces, including issues, pull requests, comments, documentation, and any other collaboration channel connected to Foodly.
